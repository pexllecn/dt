# Cognitive Grid Twin

A browser-based digital twin of the all-island transmission system in which rule-based agents monitor assets and propose decisions that a person approves. Built as a decision-support demonstration.

**Demonstration environment.** Network geometry approximate (OpenStreetMap). Telemetry synthetic, calibrated to public figures.

- Plan and decisions: [`docs/PLAN.md`](docs/PLAN.md)
- Milestone reports: [`docs/milestones/`](docs/milestones/)
- Presenter's guide: [`docs/PRESENTER.md`](docs/PRESENTER.md)

## Run

```bash
npm install
npm run dev            # http://127.0.0.1:5173
npm run build && npm run preview
```

The app opens in **Director** mode on the first script. Press `D` for **Explore**.

### Keys

| Key | Director | Explore |
|---|---|---|
| `Space` | play or pause the script | time-lapse on or off |
| `←` `→` | previous or next beat | a quarter hour back or forward |
| `1` to `4` | load a script (today, hero, storm, 2034) | load a scenario |
| `R` | reset the scenario and restart the script | reset the scenario |
| `D` | switch to Explore | switch to Director |
| `T` | Specimen or Control Room theme | same |
| `N` | narration panel | same |
| `W` | wind streamlines | same |
| `F` | fullscreen | same |
| `Esc` | close panels | same |
| `` ` `` | debug overlay (frame rate, main-thread time, pixel ratio) | same |

### URL parameters

- `mode=director|explore`, `script=today|hero|storm|y2034`, `beat=3`, `play`
- `scenario=storm`, `policy=availability`, `hours=12.5`, `theme=control`
- `view=lon,lat,distance,polar,azimuth`, `branch=<circuit label or id>`
- panels: `feed`, `notes`, `governance`, `audit`, `evidence`, `narration`, `wind`, `maturity=base`, `studies`
- `debug`, `bench`, `backend=webgl`, `quality=fixed` (turns adaptive resolution off)

### Immersive rig (four walls and a floor)

One browser window per face, on one machine, each full screen on its own display:

- `/?cave=master`: the presenter's view, which drives the faces
- `/?cave=front`, `left`, `right`, `back`, `floor`: 90 degree views from the master's eye
- `/?cave=preview`: all five faces unfolded as a cross, for rehearsal

### Narration

Each Director beat has a templated narration line (offline, the default). Optionally, a serverless function (`api/narrate.ts`) rephrases it with the Anthropic API (`claude-opus-5-5`). It is off unless the deployment sets `NARRATION_LLM=on` and `ANTHROPIC_API_KEY`. A rephrasing that changes or adds any number is discarded in favour of the template. The panel counts tokens and cost.

### Recordings

```bash
npm run build && npm run preview &
node tools/capture.mjs today --gpu     # also: hero, storm, y2034
```

`tools/capture.mjs` records a script frame by frame on a virtual clock (smooth at any render speed) and encodes `public/video/*.mp4`. The fallback card offers only the recordings present in the build. Use `--gpu` on a machine with a graphics card.

## Test

```bash
npm test               # unit tests (rules, power flow, agents, studies, corridors, narration guard)
npm run e2e            # Playwright: screenshots per milestone and every Director beat in both themes
```

## Performance

- The simulation (day of power flow, N-1 and nearly 1,000 agents) runs in a Web Worker. Changing an input recomputes the day off the render thread.
- Flow particles are laid out only on circuits near the view. Weather moves entirely on the GPU, and passes that would draw nothing are skipped.
- Panels re-render when the 15-minute interval changes, not on timers. The Director's clock lives outside React state.
- Adaptive resolution lowers the pixel ratio if the frame rate stays below 40 fps and restores it when there is headroom.
- `?bench=1` runs a fixed camera path and reports frame times. Run it on the presentation machine before the meeting.
