# Cognitive Grid Twin

A browser-based digital twin of the all-island transmission system in which rule-based agents monitor assets and propose decisions that a person approves. Built as a decision-support demonstration.

**Demonstration environment.** Network geometry approximate (OpenStreetMap). Telemetry synthetic, calibrated to public figures.

- Plan and decisions: [`docs/PLAN.md`](docs/PLAN.md)
- Milestone reports: [`docs/milestones/`](docs/milestones/)

## Run

```bash
npm install
npm run dev            # http://127.0.0.1:5173
npm run build && npm run preview
```

Useful URL parameters: `theme=control`, `hours=18.5`, `debug`, `bench`, `backend=webgl`, `view=lon,lat,distance,polar,azimuth`.

Keys: `T` theme, `D` debug, `F` fullscreen, `Space` time-lapse.

## Test

```bash
npm test               # unit tests
npm run e2e            # Playwright screenshots into docs/screens/
```

## Data

`public/data` is generated by `tools/` from public sources and committed. To rebuild: `make -C tools deps all`.
