# Cognitive Grid Twin: Clonmore station

A real-time 3D digital twin of Clonmore, a fictional 400/220/110 kV station, with rule-based agents that recommend and a person who decides.

Status: planning (milestone 1 of 8). See [docs/PLAN.md](docs/PLAN.md). No application code yet.

This folder is self-contained and separate from the national twin work elsewhere in the repository.
